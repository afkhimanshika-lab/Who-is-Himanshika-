# Himanshika | Portfolio

A personal portfolio website built to showcase my projects, skills, interests, and
learning journey as a Computer Science student.

## 🌐 About the Website

This portfolio is designed with a simple dark theme and a lime-green accent.
The goal was to keep the interface clean, modern, and easy to navigate without
making it feel overly complicated.

It includes:

- Introduction and personal profile
- Skills and technologies
- Projects I've worked on
- Contact section
- Responsive design for smaller screens
- Small hover effects and interactive elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
